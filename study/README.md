# Human study: running it

The study is a static web page in `docs/`. GitHub Pages hosts it, DataPipe
saves each participant's data to your OSF project, and Prolific sends
participants and pays them.

| File | What it is |
| --- | --- |
| `docs/index.html`, `docs/experiment.js` | the experiment (jsPsych 8, vendored in `docs/lib/`) |
| `docs/design.js` | trial assignment, seeded per participant |
| `docs/stimuli.js`, `docs/stimuli/` | stimuli generated by `study/make_stimuli.py` |
| `study/PREREGISTRATION.md` | preregistration draft |
| `study/analyze.py` | preregistered analysis |
| `study/power.md` | sample-size simulation |
| `study/test_design.js` | design checks (`node study/test_design.js`) |

## 1. Try it locally

```bash
cd docs && python3 -m http.server 8000
# open http://localhost:8000/?debug=1&quick=1
```

`debug=1` shows the data at the end instead of saving it. `quick=1` runs
only 2 trials per part. Remove both for the real study.

## 2. Host it on GitHub Pages

Repository **Settings → Pages → Build and deployment**. Choose **Deploy from
a branch**, branch `main`, folder `/docs`. The study URL is
`https://<user>.github.io/visual-cryptographic-fingerprints/`.

Participants see this URL, so it shows your GitHub username. That does not
affect anonymous peer review, but if you prefer, host `docs/` in a separate
repository.

## 3. Set up data saving (DataPipe + OSF, free)

1. Create an OSF project and a personal access token with `osf.full_write`.
2. Sign in at <https://pipe.jspsych.org>, link the token, and create a new
   experiment connected to the OSF project. Enable data collection.
3. Copy the experiment ID into `CONFIG.DATAPIPE_EXPERIMENT_ID` in
   `docs/experiment.js`.

## 4. Fill in the rest of `CONFIG`

- `PROLIFIC_COMPLETION_CODE`, from step 5
- `CONTACT`, the email address shown on the consent page

Also add your ethics-review details to the consent text (look for `ACTION`).

## 5. Create the Prolific study

- **Study URL:** your Pages URL. Turn on "URL parameters" so Prolific appends
  `PROLIFIC_PID`, `STUDY_ID` and `SESSION_ID`.
- **Completion:** choose "redirect" and copy the code into `CONFIG`.
- **Devices:** desktop only. **Estimated time:** 15 minutes.
  **Pay:** $3.00 (= $12/hour).
- **Screeners:** fluent English, approval rate ≥ 95%.
- **Places:** 8 for the pilot, then 48 for the main study (more if some are
  excluded, up to 60).

Budget at $3.00 per person plus Prolific's fee (33.3% academic, 42.8%
otherwise):

| | People | Academic fee | Standard fee |
| --- | --- | --- | --- |
| Pilot | 8 | $32 | $34 |
| Main | 48–60 | $192–$240 | $206–$257 |

## 6. Pilot, then register, then run

1. Run the pilot. Check the timing, the saved CSVs and `python study/analyze.py`.
   Pilot data are not analysed.
2. Re-run the power simulation with the pilot's variability if it differs a
   lot from `study/power.md`.
3. Register `study/PREREGISTRATION.md` on OSF or AsPredicted, with the commit hash.
4. Run the main study. Download the CSVs from OSF and run
   `python study/analyze.py data/*.csv`.

## Regenerating stimuli

```bash
for r in hex walk life_mirrored life_unmirrored voronoi; do
  python study/make_stimuli.py --rep $r --out docs
done
python study/make_stimuli.py --manifest --out docs
node study/test_design.js
```

All digests come from fixed SHA-256 namespaces, so this reproduces the same
files. Each image representation takes about 10 minutes.
